# 已知問題與修正紀錄

## 生成圖片期間切換頁面後，聊天室顯示 `Load failed`

- 發現日期：2026-07-24
- 環境：AWS EC2 production（https://safu-studio.com）
- 狀態：已在本機修正並通過測試，納入下一次 EC2 更新

### 重現方式

1. 在聊天室送出圖片生成請求。
2. 圖片仍在生成時切換到「我的圖片」。
3. 生成完成後回到聊天室。
4. 聊天室顯示 `Load failed`，但「我的圖片」已有生成完成的圖片。

### 原因

圖片生成及儲存實際上成功，但前端離開頁面後，等待中的請求或輪詢可能中斷。回到聊天室時，舊版前端沿用本機暫存狀態，沒有重新向後端核對 generation job 的最終結果，因此錯誤顯示為失敗。

### 本機修正

- 開啟聊天室時，重新從後端取得最新聊天室內容。
- 前端遇到請求錯誤時，先向後端核對 generation job；若伺服器已完成，就顯示完成結果。
- 後端讀取聊天室時，也會將已完成的 generation job 同步回聊天室訊息。
- 新增測試，涵蓋「使用者離開頁面期間工作已完成」的情況。

### 驗證結果

- 後端測試：36 passed。
- 前端 production build：成功。
- 待部署至 EC2 後，以實際切換頁面流程再驗收一次。

## 手機初始畫面需要手動縮小

- 發現日期：2026-07-24
- 狀態：已在本機修正並通過 production build，納入下一次 EC2 更新

### 原因與修正

部分內容使用固定寬度，搭配頁面最小寬度後可能超出較窄手機的 viewport。已移除頁面最小寬度、將文化元素卡片改為彈性欄寬、加入窄螢幕間距與 safe-area 支援，並避免 iPhone 聚焦小字輸入框時自動縮放。

### 待驗收

- 以實際手機直接開啟登入頁與聊天室，不應需要手動縮小。
- 測試文化元素、我的圖片、圖片詳細頁與聊天室均無水平捲動。
- 測試輸入框聚焦與返回頁面後，頁面縮放比例維持正常。
